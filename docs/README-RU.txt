WVC — виртуальная камера из области экрана (v0.3)
=================================================

Программа показывает выбранную часть экрана (или вашу веб-камеру) как камеру «WVC Camera».
Её видят Zoom, Telegram, Discord, Chrome, Edge, Firefox. Windows 10 и 11, без OBS.

Первый запуск
1. Распакуйте папку WVC в постоянное место, например C:\Programs\WVC.
2. Запустите WVC.exe, нажмите «Установить камеру» (один раз, права администратора).
3. Перезапустите Zoom/Telegram/браузер, если они были открыты.

Вкладка «Источник и картинка»
- Область / Монитор / Окно — что показывать; менять можно во время трансляции.
- Красная рамка: ярлык «перетащить» — двигать, края и углы — менять размер.
- Качество, соотношение, частота (после смены переподключите видео в Zoom).
- Поля/обрезка, поворот, увеличение центра, зеркально, курсор.

Вкладка «Камера и наложения»
- Показывать: Экран / Веб-камеру / Экран + камера в углу.
- Веб-камера включается только во время трансляции. Если её уже держит другая
  программа, WVC покажет «Веб-камера недоступна» и будет пробовать снова.
- Надпись поверх кадра (положение и размер), логотип PNG с прозрачностью.

Вкладка «Профили и клавиши»
- «Сохранить…» запоминает текущие настройки под названием, «Загрузить» возвращает.
  Первые четыре профиля можно включать клавишами.
- «Настроить горячие клавиши…» — свои сочетания для каждого действия.
  По умолчанию: Ctrl+Shift+F5 Старт/Стоп, F6 область, F7 монитор, F8 курсор,
  F9 экран↔камера, F10 камера в углу, F11 надпись, Ctrl+Shift+1…4 профили.

Сон, смена разрешения, отключение монитора: WVC сам восстанавливает захват.
Свернуть — уходит в трей. Закрыть — камера пропадёт.
Удаление: «Удалить камеру», затем удалите папку. Настройки: %APPDATA%\WVC\settings.ini.
