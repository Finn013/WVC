# WVC Phone — протокол телефон ↔ WVC (v1)

Телефон (приложение WVC Phone, Android) — **сервер**. WVC на Windows — клиент.
Все числа — little-endian. Звука нет.

## Поиск (UDP 47801)

1. WVC шлёт UDP-датаграмму `WVCP?` (5 байт ASCII) на порт **47801**: на `255.255.255.255` и на
   широковещательный адрес каждой IPv4-сети компьютера (3 раза с интервалом 0,5 с), затем ~2 с слушает ответы.
2. Телефон отвечает на адрес/порт отправителя: `WVCP!<имя>` — имя устройства (UTF-8, напр. `Samsung SM-S911B`).
3. IP телефона WVC берёт из адреса отправителя ответа. IP можно ввести и вручную (он крупно показан в приложении).

## Соединение (TCP 47800)

WVC подключается к `IP:47800`. Одновременно один клиент: новое подключение вытесняет старое.
Сразу после подключения WVC шлёт свои `SRC …` и `RES …`, телефон — `NAME …`, `RES …`, `STATE …`.

### Телефон → WVC: сообщения с заголовком

| Поле | Размер | Значение |
|---|---|---|
| magic | 4 | `WVCF` — кадр, `WVCS` — текстовое сообщение |
| length | uint32 | длина полезной части (JPEG или текст) |

**Кадр `WVCF`** — после `length` ещё 5 байт, затем JPEG:

| Поле | Размер | Значение |
|---|---|---|
| width | uint16 | ширина JPEG (как закодирован, до поворота; справочно) |
| height | uint16 | высота JPEG (справочно) |
| rotation | uint8 | 0..3 — на сколько раз по 90° **по часовой** повернуть картинку, чтобы она стала прямой |
| jpeg | length | JPEG (baseline), качество ~80 |

Камера отдаётся как её даёт сенсор + `rotation` (из CameraX `rotationDegrees` с учётом того, как держат телефон);
экран — уже прямой (`rotation = 0`). Размер по длинной стороне ~720 (по умолчанию) или ~1080.
До 30 кадров/с. Кадры **не копятся**: пока предыдущий отправляется, новые отбрасываются (минимальная задержка).
Если экран телефона не меняется, кадров может не быть — WVC держит последний.

**Текст `WVCS`** — UTF-8, одна строка без `\n`:

| Сообщение | Смысл |
|---|---|
| `NAME <имя>` | имя устройства |
| `STATE back` / `STATE front` / `STATE screen` | что сейчас показывается |
| `STATE need_consent` | выбран экран, но Android ещё не дал разрешение на запись экрана (кадров нет) |
| `STATE camera_error` | камеру не удалось открыть (нет такой камеры, занята) |
| `STATE no_camera_permission` | нет разрешения на камеру |
| `RES 720` / `RES 1080` | текущее качество |

`STATE` повторяется каждые 2 с — это и проверка связи: если от телефона ничего нет 7 с, WVC переподключается.

### WVC → телефон: текстовые строки

UTF-8, каждая заканчивается `\n`:

| Команда | Действие |
|---|---|
| `SRC back` | задняя камера |
| `SRC front` | передняя камера |
| `SRC screen` | экран телефона (без разрешения — `STATE need_consent` и запрос на телефоне) |
| `RES 720` / `RES 1080` | длинная сторона картинки |

Неизвестные команды телефон игнорирует.

## Поведение WVC

- Подключается, только пока источник «Телефон» используется (главный или второй) и идёт трансляция,
  либо после кнопки «Подключить». Повтор каждые 3 с. «Отключить» — до «Подключить» или следующего «Старт».
- JPEG декодируется через WIC (с поворотом) в BGRA и идёт в композитор как кадр веб-камеры.
- Настройки: `PhoneIp`, `PhoneSrc` (0 задняя, 1 передняя, 2 экран), `PhoneRes` (0 = 720, 1 = 1080) — в `[WVC]`, не в сценах.
  Источник: `MainSrc = 4`, `SecondSrc = 5`.
